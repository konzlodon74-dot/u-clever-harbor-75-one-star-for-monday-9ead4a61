A plain-text one-star review of Monday, written as if Monday were a
restaurant — at most 25 words and at most 180 characters, on a single line.

## Run

```sh
python3 main.py
```

This writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` by default) with no trailing newline.
